# Triage labels

Matt Pocock 工程技能使用五个标准 triage 角色。本文件记录这些角色在当前 GitHub 仓库中的实际标签名称。

| 技能中的标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 确认不处理 |

当技能描述某个 triage 角色时，使用表格中对应的 GitHub 标签。

如果 GitHub 仓库以后采用不同的标签名称，只修改右侧“GitHub 标签”列，避免创建含义重复的标签。
